One setting needs changing

This container's template has been updated since you installed it, and Unraid doesn't change an existing container's settings on its own. To match it, set Libvirt Socket to /var/run/libvirt for both the container path and the host path, then Apply.

Why?

It currently points at /var/run/libvirt/libvirt-sock, which only exists once the VM service is running. If this container starts first when the server boots, Docker makes a folder there and the VM service can't start. If that has already happened, reboot once the setting is changed. Your VMs aren't affected.
