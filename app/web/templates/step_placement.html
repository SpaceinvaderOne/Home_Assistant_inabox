This VM's network card

{{ mac }}

Give this MAC address a fixed IP in your router's DHCP settings (sometimes called a "static lease" or "DHCP reservation") before you finish installing. We recommend doing it there rather than setting a static IP inside Home Assistant itself: a static IP configured inside Home Assistant is applied by the very thing you would need network access to reach -- get the subnet or gateway wrong on this headless VM, and the only way back in is the VM's console. A router-side reservation carries none of that risk: DHCP keeps working normally, and Home Assistant just always ends up with the same address.
